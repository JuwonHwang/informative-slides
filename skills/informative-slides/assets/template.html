전체 그림Overview

미팅 주기와 기록 파일 2개의 전체 그림 Overview of the meeting cycle and its 2 record files

미팅 주기는 자료 준비, 미팅, 노트 작성이 반복되는 구조이고,
결정은 노트 작성(④)에서 미팅 노트와 GOAL.md 중 한 곳에 기록된다. The meeting cycle repeats making slides, the meeting and writing the note;
writing the note (④) records each decision in the note or in GOAL.md.

    ② → ③ → ④ → ② repeats

    ④에서 note.md 또는 GOAL.md    2. Where decisions go:
    ④ writes note.md or GOAL.md

미팅 주기 구조 1/2Meeting cycle 1/2

drive-project-forward 미팅 주기 전체 구조 (스킬 3개, 기록 2개) Full meeting cycle of drive-project-forward (3 skills, 2 records)

미팅 노트가 다음 미팅 자료의 리마인드가 되어 미팅이 한 주기로 이어지고,
GOAL.md는 사용자가 목표를 조정할 때만 바뀐다. The note becomes the reminder in the next meeting's slides, closing the cycle;
GOAL.md changes only when the user adjusts the goal.

결정별 기록 위치Where decisions go

노트 작성(④)에서 결정 종류별로 기록하는 위치 Where writing the note (④) records each kind of meeting outcome

방법이나 구현을 바꾸는 결정은 미팅 노트에만 남고, GOAL.md는 사용자가 목표 자체를 조정할 때만 바뀐다. Decisions that change the method or code stay in the note;
GOAL.md changes only when the user adjusts the goal itself.

  • 우선순위: 목표가 위에 있고, 구현은 목표를 따른다Priority: the goal sits above; the implementation follows it
  • GOAL.md 수정: 문장을 교체하고, 이력을 쓰지 않는다Editing GOAL.md: replace sentences, keep no history
