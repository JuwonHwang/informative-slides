미팅 주기 구조 1/2

informative-slides 미팅 주기 전체 구조 (스킬 3개, 기록 2개)

미팅 노트가 다음 미팅 자료의 리마인드가 되어 미팅이 한 주기로 이어지고,
GOAL.md는 사용자가 목표를 조정할 때만 바뀐다.

① 목표 작성 (goal)연구를 시작할 때 goal 스킬이
사용자에게 배경과 목표를 묻는다.
답은 GOAL.md에 처음 한 번 쓴다.

GOAL.md배경, 목표, 달성 기준, 일정을 담는다.
이후 단계는 GOAL.md의 달성 기준으로
결과를 판단한다.

② 자료 준비 (meet)meet 스킬이 GOAL.md, 미팅 노트,
git log, run 기록을 읽는다.
읽은 내용으로 설명 자료(.md)를 쓰고
슬라이드(.html)로 만든다.

③ 미팅사용자가 설명 자료로
방법과 결과를 확인한다.
그다음 바꿀 것과 할 일을 정한다.

④ 노트 작성 (meet)meet 스킬이 사용자가 정한 것(■)을
미팅 노트(note.md)에 쓴다.
다음 미팅의 ② 자료 준비가
note.md를 리마인드로 읽는다.
