# 장 배치 파일

장 배치마다 파일 하나에 그 배치를 쓴 예시 장 하나가 있다. 덱을 만들 때는 그 덱에 쓰는 배치의 파일만 읽어 쓴다.
파일 이름은 `<배치 이름>.html`이고, 배치 이름은 장의 `data-layout` 값이다. 그림을 쓰는 배치의 파일에는 그 장이 쓰는 SVG 그림 원본이 함께 있다.
장 안에 넣을 디자인 요소(그래프, 표, 강조 상자 들)는 `../elements/`에 요소마다 있다.

| 배치 이름 | 쓰는 곳 |
|---|---|
| `cover` | 표지: 소속과 로고, 프로젝트 이름과 한 줄 설명, 제목, 발표자와 날짜 |
| `project` | 프로젝트 소개: 프로젝트 전체 구조에서 이 자료가 다루는 부분만 진하게 남긴 그림과 사용자·만드는 것·범위 불릿 |
| `summary` | 요약: 리캡(목적, 문제, 답)과 번호 항목 |
| `overview` | 전체 처리 과정: 방법 단계 배치. 첫 단계는 그림 전체, 이후 단계마다 처리 한 걸음만 진하게 |
| `method` | 방법 설명: 왼쪽 그림, 오른쪽 단계 설명. 단계마다 지금 단계의 부분만 진하게 |
| `table` | 수치 표: 비교 표와 강조 행 |
| `divider` | 절 구분: 절 번호와 수, 절 이름, 그 절이 답하는 질문 |
| `zoom` | 확대: 전체 그림 위의 확대 영역과 확대도, 오른쪽 설명 |
| `options` | 선택지: 선택지마다 그림과 바뀌는 것 한 줄 |
| `closing` | 마무리: 프로젝트 이름, 결정 항목과 결정권자, 기한 |
