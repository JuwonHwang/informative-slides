# 요소 파일

디자인 요소마다 파일 하나에 그 요소를 쓴 장 하나가 있다. 덱을 만들 때는 문서의 `요소`에 나온 요소의 파일만 읽어 쓴다.
장 배치(표지, 요약, 방법 설명 들)는 `../layouts/`에 배치마다 있다. 파일 이름은 `<요소 이름>.html`이다. 그림 요소의 파일에는 그 장이 쓰는 SVG 그림 원본(`<template id="diagram-…">`)이 함께 있다.

| 요소 이름 | 묶음 | 요소 | 쓰는 곳 |
|---|---|---|---|
| `box` | 그림 부품 | 처리 상자 | 모델, 층, 서비스처럼 처리하는 구성 요소의 둥근 상자 |
| `cell` | 그림 부품 | 데이터 칸 | 입력, 행렬, 파일 같은 데이터의 각진 칸과 격자 |
| `edge` | 그림 부품 | 화살표 | 데이터가 옮겨 가는 경로와 조건부 경로 |
| `group` | 그림 부품 | 묶음 테두리 | 한 모듈로 묶이는 요소를 감싸는 테두리 |
| `op` | 그림 부품 | 원소 연산 기호 | ⊕, ⊗, exp, max처럼 원 안에 쓰는 연산 |
| `focus` | 그림 부품 | 강조 방식 | 단계와 부분 강조에서 지금 설명하지 않는 부분을 처리하는 방법 |
| `figure` | 그림 부품 | 그림 패널 | 그림과 그래프를 올리는 바탕 |
| `chart` | 그래프 | 그래프 공통 | 막대, 선, 점 그래프가 함께 쓰는 격자, 축, 글자, 계열 이름 |
| `bar` | 그래프 | 막대 그래프 | 범주마다 값을 막대로 비교한다 |
| `line` | 그래프 | 선 그래프 | 순서가 있는 값의 변화를 선으로 보인다 |
| `scatter` | 그래프 | 점 그래프 | 두 값의 관계를 점으로 보인다 |
| `heading` | 텍스트 상자 | 제목과 머리표 | 장 맨 위의 머리표(절 이름)와 제목 |
| `lead` | 텍스트 상자 | 메시지 | 장마다 한 문장으로 쓰는 메시지 |
| `narration` | 텍스트 상자 | 단계 설명 | 그림 옆에서 단계마다 바뀌는 설명 상자 |
| `callout` | 텍스트 상자 | 강조 상자 | 반드시 기억할 사실(crit)이나 처음 보는 결과(new)를 한두 문장으로 |
| `recap` | 텍스트 상자 | 요약 리캡 | 요약 장의 목적, 문제, 답 세 줄 |
| `caption` | 텍스트 상자 | 캡션과 출처 | 그림 아래 캡션과 장 아래 출처 |
| `table` | 표와 목록 | 표 | 수치를 비교하는 표 |
| `bullets` | 표와 목록 | 불릿 | 라벨로 시작하는 짧은 구의 목록 |
| `option` | 표와 목록 | 선택지 패널 | 결정의 선택지를 나란히 그리는 패널 |
